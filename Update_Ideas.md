GAME MOCKUP: FEEDBACK AND CHANGES

LAYOUT AND SCREEN
- Make the courtroom fill the full screen so there is no scrolling.
- Put the top bar inside the courtroom frame, and keep it small.
- Top bar shows only: cases to complete, timer, points, and reputation.
- Don't put everything in boxes. When a case pops up, show just the words, not an outlined box.

VISUAL STYLE
- Change the font.
- Make the colors more vibrant.
- Give the buttons different colors.
- Show reputation as a color instead of a bar.
- Turn the circle in the background into a clock that ticks the time.

INTERACTIVE ITEMS
- Case file: show it as a file icon. Clicking it opens tabs for the different files.
- Law book: show it as a book icon. Clicking it opens a tab with all the laws.
- Gavel: use a real gavel image. Players click the gavel to bang it.
- Envelope: animate it flying in. The player clicks it, and then the explanation appears.

GAMEPLAY
- Do 4 cases per day.
- Don't show the charge the person is accused of. Players use the law book to piece it together themselves.
- Refusing a case counts as reporting it, so combine them into one action.
- Make the first day an introductory example that shows how to play.
- Show the envelope payout as a big jump. For example, a small case pays about $500.

POINTS AND FEEDBACK
- Don't just add up the total at the end. Show points popping up and adding in real time.
- Shorten the "right call" screen after a case is finished.

DAILY GAVEL PAPER (END OF DAY)
